Cargo-IMP Validation

This provides the means by which 29th Edition IATA/ATA Cargo-IMP messages may be syntactically validated.

Select the message type, enter the message and then press the Validate button. Valid messages will simply be reflected back in the output box whereas an error, highlighting the location of a structural problem, will be shown for invalid messages.
