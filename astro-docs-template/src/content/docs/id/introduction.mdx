## <iconify-icon icon="material-symbols:balance" width="24" height="24"></iconify-icon> Ruang Lingkup (Scope)
APP MAU adalah sistem terintegrasi untuk pengelolaan gudang lini 1 di Bandara Soekarno-Hatta, meliputi:
<PointerList
  items={[
    { text: 'Pelaporan pendapatan ke Angkasa Pura II' },

Sistem berjalan pada server cloud, bersifat API-driven, dan terhubung dengan stakeholder eksternal.

## <iconify-icon icon="material-symbols:security" width="24" height="24"></iconify-icon> Keamanan Sistem (Security)
- HTTPS dengan SSL
- Token-based authentication (JWT)
- Firewall server aktif
- Hak akses berbasis role internal
- Supervisor memastikan sistem auto-restart jika crash
- Akses server terbatas menggunakan SSH Key

---

## <iconify-icon icon="material-symbols:settings-slow-motion" width="24" height="24"></iconify-icon> Availability & SLA
- Sistem dirancang berjalan 24/7
- Supervisor menjaga service tetap aktif
- Jika server restart, semua service otomatis hidup
- Waktu pemulihan kegagalan (RTO): ± 5–10 menit

---

## <iconify-icon icon="material-symbols:home-storage-rounded" width="24" height="24"></iconify-icon> Backup & Restore
- Backup database dilakukan secara berkala melalui skrip otomatis (opsional menyesuaikan implementasi)
- File log disimpan untuk audit
- Restore dilakukan melalui database snapshot

---

## <iconify-icon icon="material-symbols:nest-clock-farsight-analog" width="24" height="24"></iconify-icon> Logging & Monitoring
- Log API dan service disimpan di server
- Bisa diintegrasikan dengan ELK Stack (Elasticsearch / Logstash / Kibana) jika diperlukan
- Monitoring uptime dapat menggunakan tools eksternal: UptimeRobot / Grafana

---

## <iconify-icon icon="material-symbols:repeat-one-on-rounded" width="24" height="24"></iconify-icon> Maintenance
- Update dependency melalui Poetry dan npm
- Maintenance dilakukan oleh tim IT MAU
- Perubahan sistem didokumentasikan pada repository versi kontrol

## <iconify-icon icon="material-symbols:conversion-path" width="24" height="24"></iconify-icon> Versi & Pengembangan
- Sistem dalam fase aktif pengembangan

## <iconify-icon icon="material-symbols:summarize" width="24" height="24"></iconify-icon> Kesimpulan
APP MAU adalah sistem warehouse management yang terintegrasi dengan pihak regulator, berjalan di cloud, aman, dan mampu melakukan otomasi pelaporan operasional secara real-time.
