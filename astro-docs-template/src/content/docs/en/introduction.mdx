## 2. Scope
APP MAU is an integrated warehouse management system for Line 1 of Soekarno-Hatta Airport, providing:
- Revenue reporting to Angkasa Pura II
- Cargo tracking reporting to Ministry of Transportation (HUBNET)
- Customs monitoring and auditing (TPS Online)
- Warehouse operational activities (CTOS): invoicing, weighing, manifest processing, cargo status updates

The system runs on cloud infrastructure and communicates via REST API.

## 5. System Architecture
- Astro frontend communicates with FastAPI via REST API
- Redis used for caching and messaging
- APScheduler handles automated background tasks
- External system communication via JSON over HTTPs

General Flow:
```
Client → Frontend → FastAPI Backend → Database / External API
```

## 6. Application Modules
### ✅ 1. AP2 (Angkasa Pura II)
- Daily revenue submission
- Automated JSON + PDF report delivery
- REST API integration

### ✅ 2. HUBNET (Ministry of Transportation)
- Tracks inbound and outbound cargo
- Automatically submitted via REST API

### ✅ 3. TPS ONLINE (Customs)
- Warehouse stock and status visibility
- Audit & cargo release process
- Migration from CodeIgniter 3 to FastAPI

### ✅ 4. CTOS (Warehouse Operational System)
- Invoice generation
- Digital weighing machine integration
- Airline manifest import (FFM/FWB/FHL)
- Cargo status submission to airlines

## 7. Security
- HTTPS encryption with SSL
- Token-based authentication (JWT or similar)
- Role-based authorization
- SSH-key restricted server access
- Firewall enabled
- Automatic service recovery via Supervisor
