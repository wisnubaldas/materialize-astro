# ⚡ Cara Menjalankan asdasdasdsdasdasdasd

```bash
# 1. Install mkdocs dan tema material
pip install mkdocs mkdocs-material pymdown-extensions

# 2. Jalankan lokal
mkdocs serve

# 3. Build versi production
mkdocs build

# 4. Deploy ke static hosting / GitHub Pages / Netlify
mkdocs gh-deploy
```

> Jangan masuk ke venv langsung jalan kan dengan mode `mkdocs serve -v`
