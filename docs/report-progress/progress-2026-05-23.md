## Ringkasan Perubahan

Kami telah memperbaiki format dan tata letak dokumen PDF manifest build-up (`build_up_manifest_pdf.html`) agar siap untuk dokumen multi-halaman:
1. **Perataan Teks Kolom "NUMBER OF PIECES"**: Mengatur perataan teks kolom "NUMBER OF PIECES" rata kanan pada baris entri data MAWB, baris Total ULD, dan baris Grand Total menggunakan selector CSS spesifik tanpa mengotori elemen HTML dengan inline styling classes.
2. **Perbaikan Halaman PDF di Pojok Bawah Kanan**: Menggunakan fitur margin page box `@bottom-right` native WeasyPrint untuk merender nomor halaman dinamik ("Page X of Y"), sehingga nomor halaman selalu tercetak di pojok bawah kanan setiap halaman dokumen PDF.
3. **Pencegahan Duplikasi Grand Total**: Memindahkan baris GRAND TOTAL dari elemen `<tfoot>` ke akhir elemen `<tbody>` sehingga GRAND TOTAL hanya tercetak satu kali di akhir dokumen (pada halaman terakhir), bukan berulang di setiap halaman transisi.
4. **Dukungan Multi-halaman Dinamis**: Meng-override batasan tinggi tetap dan properti `overflow: hidden` pada layout Paper CSS `.sheet` sehingga data yang melebihi satu halaman dapat mengalir (page-break) ke halaman berikutnya dengan rapi tanpa terpotong.
5. **Perbaikan Judul Dokumen (.title) agar Center**: Mengatur lebar `body` dan `.sheet` menjadi `100% !important`, serta `.title` menjadi `width: 100%` dan menghapus properti `position: fixed` pada `table`. Hal ini memperbaiki document flow dalam PDF paged media, memastikan judul dokumen terpusat secara presisi di tengah halaman (align center) relatif terhadap lebar tabel dan halaman.
