## Gap / Risiko

- Form tambah Master berada dalam mode konten screen Master MAWB, bukan route terpisah. Jika nanti dibutuhkan UX yang benar-benar screen terpisah, route tambahan bisa dibuat tanpa mengubah API service.
- Menu EDI dan Warehouse di footer sudah tampil sebagai icon menu, tetapi belum aktif karena route/screen terkait belum tersedia di mobile app.
- Penambahan menu baru cukup dilakukan di `menu.json`, tetapi route target tetap perlu dibuat di `app/` agar menu bisa aktif.
- Screen rincian menerima context header/detail dari route params; setelah kembali ke daftar Master, data akan dimuat ulang dari backend oleh screen Master MAWB.
- Endpoint reopen sekarang membutuhkan payload `mawb` dan `total_pieces`; client lama yang masih mengirim body kosong perlu disesuaikan.
- Status selesai dihitung dari akumulasi rincian pieces. Data lama yang pieces-nya sudah penuh akan otomatis masuk daftar selesai meski status detail lama belum tersinkron.
- List Build Up selesai default memakai tanggal lokal perangkat. Jika perangkat user salah tanggal, filter default juga ikut bergeser.
- Summary dashboard sekarang all-time dan memakai endpoint backend khusus. Jika nanti butuh filter tanggal/periode, endpoint bisa diperluas dengan query parameter tanpa mengubah card dashboard.
- `MetricCard` memakai layer bentuk dekoratif berbasis `View` dan `LinearGradient` agar tetap Expo-compatible tanpa dependency native tambahan.
- Slot `topContent` pada `MetricCard` menerima elemen bebas; pemakai perlu menjaga ukuran konten agar tidak menutup title pada layar kecil.
- Toggle dark mode NativeWind membutuhkan strategi `class`; konfigurasi ini wajib dipertahankan jika Tailwind setup diubah lagi.
- `MetricCard` sekarang khusus counter/angka, sedangkan header/action memakai `HeaderMetricCard`.
- Varian visual card tersedia untuk `MetricCard`, `HeaderMetricCard`, dan komponen lain yang memakai `PatternedCard`.
