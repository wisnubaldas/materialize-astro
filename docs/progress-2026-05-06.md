# Progress 2026-05-06

## Ringkasan Perubahan

- Menutup gap keamanan frontend dengan menghapus file env yang ter-track dan berisi secret, lalu menyiapkan template konfigurasi aman.
- Menyelaraskan dokumentasi frontend agar tidak lagi menampilkan contoh secret literal.
- Menghapus verifikasi JWT lokal di frontend SSR middleware (yang sebelumnya bergantung pada `AUTH_JWT_SECRET`) dan menggantinya dengan validasi melalui endpoint backend `/auth/me`.
- Menambahkan timeout eksplisit pada wrapper HTTP frontend (`PUBLIC_API_TIMEOUT_MS`, default 15000 ms) dengan `AbortController`.
- Menutup gap JavaScript-first dengan migrasi modul frontend dari `.ts` ke `.js` pada area API, auth, middleware, dan util.
- Menghapus `astro/tsconfig.json` karena tidak lagi dipakai setelah migrasi JavaScript-first (build tetap hijau).
- Membersihkan dependency legacy yang tidak terpakai: `jsonwebtoken` dan `@types/jsonwebtoken`.
- Menambahkan `astro/jsconfig.json` untuk menjaga resolusi alias path (`@components`, `@lib`, dll.) pada tooling lint/check setelah migrasi dari `tsconfig.json`.
- Memperjelas import komponen warehouse ke ekstensi `.jsx` agar resolver lint lebih konsisten.
- Mengubah alur modul Warehouse Buildup: hasil pencarian Master AWB tidak lagi langsung submit manifest, tetapi disimpan sebagai draft.
- Menambahkan tab baru Draft Manifest untuk menampilkan, submit, dan hapus draft.
- Menambahkan penyimpanan draft ke `localStorage` agar proses pencarian berulang menambah draft baru.
- Menyempurnakan alur Draft Manifest: submit per-draft dihapus dan diganti menjadi satu tombol submit global pada tab Draft untuk menggabungkan seluruh draft menjadi satu payload submit (satu proses pembentukan nomor buildup).
- Memperbaiki error runtime `warehouseClient is not defined` pada modul buildup form.
- Menambahkan logging error API server ke browser console pada wrapper API frontend untuk debugging cepat.
- Memperbarui aturan `AGENTS.md` dan `astro/frontend_agent.md` agar kegagalan fetch wajib log detail error server ke `console.error`.
- Menutup gap dokumentasi harian dengan menambahkan progress report tanggal hari ini.
