## Tanggal Eksekusi
2026-04-28

## Ringkasan Perubahan
- Memperbaiki seluruh nama index migration CEISA expansion agar kompatibel dengan batas identifier MySQL 64 karakter.
- Menambahkan hardening pada migration `aa0000000008` (`mst_ceisa_reference_jenis_transaksi_perdagangan`) agar aman rerun setelah kegagalan parsial:
  - create table conditional,
  - create index conditional,
  - seed hanya jika tabel kosong.
- Menambahkan hardening pada migration `aa000000001c` (`mst_ceisa_reference_satuan_barang`) untuk menangani error charset:
  - create table conditional,
  - convert tabel ke `utf8mb4_unicode_ci`,
  - create index conditional,
  - seed hanya jika tabel kosong.
- Menambahkan opsi `mysql_charset="utf8mb4"` dan `mysql_collate="utf8mb4_unicode_ci"` pada migration create-table CEISA expansion agar konsisten.
