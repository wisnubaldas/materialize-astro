## 🧩 FastAPI–Astro Wiki: Cross-Origin Resource Sharing (CORS)

### 🎯 Tujuan

Mengamankan komunikasi lintas domain antara frontend (Astro) dan backend (FastAPI) agar hanya sumber yang sah dapat mengakses API.

<hr />

### 🔍 Mengapa Ada CORS

CORS adalah mekanisme keamanan browser untuk mencegah situs jahat mencuri data dari domain lain.
Browser memblokir request lintas domain kecuali server secara eksplisit mengizinkannya.

<hr />

### 🧠 Cara Kerja

1. Browser mengirimkan preflight request (OPTIONS) untuk memeriksa izin.
2. Jika backend membalas dengan header Access-Control-Allow-Origin, request dilanjutkan.
3. Jika tidak, browser memblokir response — bukan server yang menolak.
<hr />

### ⚙️ Implementasi di FastAPI

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://110.239.87.173:4321",
        "https://app.mitraadira.com",
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

```

<hr />

### 🌍 Topologi Request

1. ❌ Terblokir oleh CORS: origin frontend ≠ backend dan tidak diizinkan.
2. ✅ Diizinkan CORS: origin berbeda tapi diizinkan lewat header.
3. 🏡 Same-Origin: domain, port, dan protokol sama → tidak perlu CORS.

(Lihat diagram di atas untuk visualisasi lengkap.)

### 🔐 Best Practice

1. Gunakan daftar origin eksplisit, hindari wildcard \* pada API sensitif.
2. Selalu aktifkan allow_credentials=True jika memakai cookie/token.
3. Gunakan HTTPS di production agar kredensial aman.
