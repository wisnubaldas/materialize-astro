## Visualisasi dengan Mermaid

Mermaid memudahkan dokumentasi teknis dengan diagram yang ditulis langsung dalam Markdown. Berikut beberapa contoh yang sering dipakai.

### Flowchart

<div class="mermaid">
{`graph TD
    A[Mulai] --> B{Pengguna login?}
    B -- Ya --> C[Ambil profil]
    C --> D[Render dashboard]
    B -- Tidak --> E[Tampilkan layar login]
    E --> B`}
</div>

### Class Diagram

<div class="mermaid">
{`classDiagram
    class User {
      +string id
      +string email
      +login()
    }
    class Session {
      +string token
      +Date expiresAt
      +refresh()
    }
    class AuditLog {
      +string id
      +string action
      +Date createdAt
    }
    User "1" --> "1" Session : memiliki
    User "1" --> "*" AuditLog : menghasilkan`}
</div>
