## Gap / Risiko

- Response `errors: []` pada 500 adalah perilaku aman untuk production.
- Root cause PDF Build Up adalah permission folder `app/storage/generated_pdf` karena proses aplikasi berjalan sebagai user Supervisor.
- Post-build JS minify sekarang default skip. Jika butuh kompresi tambahan, jalankan build dengan `MINIFY_JS=true`, tetapi estimasi manfaat dari log terakhir hanya sekitar 0.8%.
- Generate PDF masih sinkron di backend sehingga durasi tombol tetap bergantung pada WeasyPrint dan kapasitas CPU VM.
- Cache PDF mempercepat request berulang selama data Build Up belum berubah. Generate pertama tetap membutuhkan waktu render PDF.
- Layout Build Up Checklist PDF dipertahankan, tetapi tetap perlu spot check visual pada data operasional asli setelah deploy karena dokumen cetak sensitif terhadap engine font/rendering.
- File font lokal menambah ukuran repository sekitar 1.1 MB, tetapi membuat render PDF lebih mandiri dan tidak bergantung koneksi internet ke Google Fonts.
- Air Cargo Manifest PDF sekarang memakai font lokal yang sama, sehingga render manifest juga tidak bergantung koneksi ke Google Fonts.
