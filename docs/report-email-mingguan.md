# Report Mingguan

Buatkan saya report dengan format email kepada stakeholder, manager dan supervisor IT. Minimalisir bahasa teknis ketika membuat report, agar pihak management mudah memahami. Output report lebih pada pencapaian dari aplikasi yang saya buat. Adapun project yang saya kerjakan adalah :

1. [Backend FastApi](materialize-fastapi)
   Aplikasi ini adalah aplikasi porting dari aplikasi gudang bernama CTOS. Aplikasi ini berperan sebagai backend API saja.
2. [Frontend Astro + React](astro)
   Aplikasi ini adalah aplikasi frontend dari backend diatas. aplikasi ini yang berinteraksi dengan user langsung.
3. [Desktop Aplikasi](desktop-app)
   Aplikasi ini adalah aplikasi desktop sebagai pendukung aplikasi CTOS untuk operasional gudang. aplikasi ini di buat menggunakan C# + WPF. dan hanya berjalan di os Windows.
4. [Mobile Aplikasi](mobile-app)
   Sama seperti aplikasi desktop. saya menggunakan Expo + React Native.

Buatkan laporannya, rangkum progress dari file-file `docs\report-progress`. Tempatkan laporan mingguan di folder `docs\report-mingguan`.
