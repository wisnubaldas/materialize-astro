### Menemukan perbedaan antara stok fisik dan data tercatat.
### Meminimalkan risiko kerugian akibat kehilangan atau kerusakan barang.
### Mengecek kondisi barang dan mengelola stok yang hampir kedaluwarsa menggunakan metode seperti "First Expired, First Out" (FEFO).

> **Full count**: Menghitung seluruh inventaris pada satu waktu tertentu.
>
> **Cycle count**: Menghitung sebagian inventaris secara rutin (misalnya, mingguan atau bulanan) untuk menjaga akurasi tanpa mengganggu operasional.
