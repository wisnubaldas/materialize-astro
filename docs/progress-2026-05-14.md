## Gap / Risiko

- Data dashboard masih placeholder UI dan belum terhubung ke endpoint backend.
- Menu dashboard selain Build Up masih belum memiliki route aktif.
- Preview visual manual di device fisik tetap perlu dilakukan karena perbedaan ukuran layar dan status bar Android/iOS.
- NativeWind versi saat ini tidak kompatibel dengan `nativewind/babel` atau `jsxImportSource: 'nativewind'`; gunakan cache clear saat konfigurasi styling berubah.
- Migrasi Expo Router perlu dilakukan bertahap karena project masih memiliki `AppNavigator` dari React Navigation.
- Worktree masih dirty dari perubahan sebelum audit Fase 0. Sebelum masuk fase dependency atau routing, sebaiknya review diff dan commit/simpan checkpoint agar perubahan UI, konfigurasi NativeWind, dan migrasi berikutnya tidak tercampur.
- Branch audit lokal belum punya upstream. Ini aman untuk menghindari push ke `origin/master`, tetapi perlu remote/branch tujuan yang disepakati sebelum push.
- Template sumber memakai NativeWind `^4.1.23`, Tailwind CSS `^3.4.17`, dan TypeScript. Project MAU APP Mobile saat ini memakai NativeWind `^5.0.0-preview.3`, Tailwind CSS `^4.3.0`, dan JavaScript-only, sehingga port komponen harus manual, kecil, dan diverifikasi per fase.
- `separator` tidak tersedia sebagai file standalone di template sumber; jika dibutuhkan, implementasi MAU APP harus berupa primitive `View` sederhana.
- `expo-router` sudah tersedia tetapi belum menjadi entry runtime. Fase 2A harus membuat route JavaScript terlebih dahulu sebelum mengubah `main` ke `expo-router/entry`.
- `app.json` kini memuat plugin `expo-router`; export tetap berhasil dengan entry lama, tetapi perubahan routing berikutnya perlu diverifikasi ulang di web dan Android.
- Setelah Fase 2A, bundle utama naik karena Expo Router ikut masuk ke graph: web dari sekitar 1.32 MB ke 1.54 MB dan Android dari sekitar 4.17 MB ke 4.68 MB. Ini masih diterima untuk fase migrasi routing, tetapi perlu dipantau pada fase cleanup/WPO.
- `src/navigation/AppNavigator.js` masih dipertahankan sebagai compatibility layer. Cleanup file ini dan import terkait sebaiknya dilakukan setelah manual QA memastikan login, dashboard, dan Build Up stabil di web serta device fisik.
- Bundle Fase 3 naik tipis karena dependency `clsx` dan `tailwind-merge` kini masuk graph melalui `AppButton`. Kenaikan ini perlu dipantau saat komponen UI bertambah, tetapi masih sesuai tujuan utility reusable.
- `Text` baru memakai `class-variance-authority`; bundle web naik tipis ke sekitar 1.58 MB. Masih wajar untuk fase UI foundation, tetapi tetap perlu dipantau.
- Komponen lama `AppButton`, `AppInput`, dan `InfoCard` masih ada sebagai wrapper compatibility. Ini sengaja untuk menekan risiko refactor besar; cleanup atau penggantian import langsung bisa dilakukan pada Fase 10/13.
- `AppNavigator` masih ada sebagai compatibility layer React Navigation. Karena `package.json` sudah memakai `expo-router/entry`, file ini tidak menjadi route utama, tetapi cleanup tetap perlu setelah manual QA.
