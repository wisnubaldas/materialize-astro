## Detail Chain Fallback yang Diimplementasikan

### Perbaikan get_legacy_weighing_header() — 3-Step Strategy

```
Attempt 1: MasterAWB + FlightNumber LIKE + DateOfFlight LIKE  (filter ketat)
Attempt 2: MasterAWB + DateOfFlight LIKE  (jika flight_no format berbeda)
Attempt 3: MasterAWB saja  (ambil record terbaru — fallback terakhir)
```

### Data Header FFM (generate_ffm_build_up_preview)

```
carrier  : header.airlines → weighingheader.AirlinesCode → hostawb.airlinescode → invoiceheader.AirlinesCode
origin   : weighingheader.Origin (via 3-step fallback query)
dest     : header.dest → weighingheader.Destination
```

### Data Detail per MAWB (_map_ffm_detail)

```
pieces   : rincian(sum) → detail.total_pieces → detail.master_total_pieces
           → weighingdetail.Pieces → weighingheader.TotalPieces
           → hostawb.Quantity → invoiceheader.TotalPieces

weight   : rincian(sum) → weighingdetail.GrossWeight → weighingdetail.NettoWeight
           → weighingheader.TotalNetto → hostawb.Weight
           → invoiceheader.TotalNetto

volume   : SUM(eks_weighingdetail.VolumeCargo WHERE MasterAWB)   [BARU — dijumlah semua baris]
           → SUM(eks_weighingheader.TotalVolume WHERE MasterAWB)  [BARU — dijumlah semua baris]
           → hostawb.Volume
           → LongCargo x WidthCargo x HighCargo / 1_000_000
```
