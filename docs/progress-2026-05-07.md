## Update Lanjutan 2026-05-07

### Ringkasan Perubahan Tambahan

- Perbaikan `astro/src/components/edi/fwbGenerator.js` untuk menyesuaikan format `FWB/17` ke grammar parse2:
  - Header quantity-weight menjadi satu segmen (`T{pieces}K{weight}`).
  - Struktur party `SHP/CNE` menjadi multi-line sesuai Cargo-IMP (`SHP`, `NAM`, `ADR`, `LOC`, `/CC`).
  - Segment `AGT` dinormalisasi ke numeric IATA agent code (7 digit) + multi-line name/place.
  - Segment `RTD` disusun ulang ke kolom standar (`P/K/C/W/R/T`) dan goods description dipindah ke line `/NG/...`.
  - Segment `PPD` disusun ulang ke dua baris (`PPD/WT...` lalu `/OA.../OC.../CT...`).
  - Segment `CER` dan `ISU` dipotong ke batas panjang field Cargo-IMP.
  - Segment `REF` diubah ke pola sender participant (`REF///AGT/{participant}/{origin}`).
