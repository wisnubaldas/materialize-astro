  items={[

## <iconify-icon icon="material-symbols:security" width="24" height="24"></iconify-icon> System Security (Security)
- HTTPS with SSL
- Token-based authentication (JWT)
- Active server firewall
- Internal role-based access rights
- Supervisor ensures system auto-restart if it crashes
- Limited server access using SSH Key

---

## <iconify-icon icon="material-symbols:settings-slow-motion" width="24" height="24"></iconify-icon> Availability & SLA
- The system is designed to run 24/7
- Supervisor keeps the service active
- If the server restarts, all services will automatically start
- Failure recovery time (RTO): ± 5–10 minutes

---

## <iconify-icon icon="material-symbols:home-storage-rounded" width="24" height="24"></iconify-icon> Backup & Restore
- Database backups are performed periodically via automated scripts (optional to customize implementation)
- Log files are saved for auditing
- Restore is done via snapshot database

---

## <iconify-icon icon="material-symbols:nest-clock-farsight-analog" width="24" height="24"></iconify-icon> Logging & Monitoring
- API and service logs are stored on the server
- Can be integrated with ELK Stack (Elasticsearch / Logstash / Kibana) if needed
- Uptime monitoring can use external tools: UptimeRobot / Grafana

---

## <iconify-icon icon="material-symbols:repeat-one-on-rounded" width="24" height="24"></iconify-icon> Maintenance

## <iconify-icon icon="material-symbols:summarize" width="24" height="24"></iconify-icon> Conclusion
APP MAU is a warehouse management system that is integrated with regulators, runs in the cloud, is secure, and is capable of automating real-time operational reporting.
