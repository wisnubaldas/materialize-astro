## Hasil Verifikasi

- Script menyediakan opsi periode `--start` dan `--end`, mode default 7 hari terakhir dari progress terbaru, pilihan model Gemini, timeout, `--max-output-tokens` opsional, serta `--dry-run` untuk memeriksa prompt tanpa memanggil API.
- Script dapat membaca `GEMINI_API_KEY` dari environment variable atau file `docs/weekly-report-generator/.env` lokal.
- Script menyediakan opsi `--send-email` dengan konfigurasi SMTP dari `.env`, termasuk banyak penerima To/CC/BCC menggunakan pemisah koma atau titik koma.
- Script menyediakan opsi `--fallback-models`, `--model-retry-delay`, dan `--no-auto-model-fallback`; wrapper cron juga meneruskan konfigurasi `GEMINI_FALLBACK_MODELS` dan `GEMINI_MODEL_RETRY_DELAY`.
- Script dapat mengambil daftar model dari endpoint Gemini `v1beta/models`, memfilter model yang mendukung `generateContent`, lalu mencobanya sebagai fallback dinamis saat model sebelumnya terkena limit/error transient.
- Script tidak lagi memotong isi progress harian maupun report sebelumnya saat menyusun prompt.
- Deploy script development dan production mengatur ownership `wisnu:wisnu`, permission executable untuk `run_weekly_report.sh`, permission private untuk `.env`, dan file `weekly-report.log` yang writable oleh cron user.

## Gap / Risiko

- API key harus diset melalui environment variable `GEMINI_API_KEY` dan tidak boleh disimpan di repository.
- Pengiriman email bergantung pada kredensial mailbox, SMTP AUTH, MFA/app password, dan akses port 587 dari jaringan lokal.
